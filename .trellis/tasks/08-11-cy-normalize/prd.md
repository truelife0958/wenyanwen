# 词义默写格式统一 + 答案串位修复

## Goal

统一全部词义默写题格式(考点【】标注、去除重复考点词、多考点分行),用 learning notes 修复答案串位(周亚夫/陈涉世家/邹忌/饮酒等篇),消除"下划线/书名号混用、挨得太近"问题。

## Background (扫描已确认)

- 格式混乱(约 600+ 题):`薄如【钱唇】 钱唇： ___`(【】高亮后冒号前重复裸考点词)、`1.  阈：___`(无【】)、`【和】纸灰之类【冒】之和： ___ 冒： ___`(多考点密集无分隔)。
- **答案串位**(book 词义 answers 整体错位):周亚夫军细柳 13 题全答"侵入边境"、陈涉世家全答"去，往"、邹忌讽齐王纳谏全答"讽谏…"、饮酒全答"尘世"、春望全答"长安城…"、渡荆门全答"往"、钱塘湖全答"刚刚"、使至塞上 长河/征蓬 答案互换。
- **权威来源**:learning.json notes(1553 条 `{char, text}` 词级注释)匹配率 80-100%。

## Requirements

### R1. 格式统一 (脚本 scripts/moxie/normalize-cy.py)
- 单考点题:`句子【考点】： ___`(删除冒号前重复裸考点词)。
- 多考点题:`句子【考点1】…【考点2】…：` + 换行 `考点1：___ 考点2：___`(标签行空格分隔)。
- 无【】题:冒号前裸词包【】。
- 考点标签与句子/输入框间距由渲染层处理。

### R2. 答案修复
- 考点词在 learning notes 精确匹配(char == 词)→ 用 text 替换 answers。
- 匹配不到:保留现有 answers;answers 与考点数不符 → 标记记录。
- 修复后 validate: 答案数 == 考点数(词义题)。

### R3. 渲染层 (moxie.css / MoxieArticle.tsx)
- `.moxie-word` 加左右 margin(词与文字间距)。
- q 中 `\n` 渲染为换行(white-space: pre-wrap 或分行)。
- 考点标签 `词：` 与输入框间距。

### R4. 验证
- validate 段 13 新增:词义题 q 必含【】;答案数==考点数;答案非串位(抽查)。
- check + test:flow 全绿;浏览器实测周亚夫/陈涉世家词义。

## Acceptance Criteria

- [ ] 全部词义题 q 含【】,无冒号前重复裸考点词
- [ ] 串位篇答案全部修复(notes 匹配率可证明)
- [ ] 多考点题标签行渲染清晰不拥挤
- [ ] validate 新断言通过;check + test:flow 全绿
- [ ] 修复记录 research/fix-record.md
