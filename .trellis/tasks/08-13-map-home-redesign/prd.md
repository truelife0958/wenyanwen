# 主页面 = 画布式闯关地图: 首页纯地图 + 地图重做 + TabBar 两 tab

## Goal

整个应用的主页面（`/`）就是**一个好看的画布式闯关地图**，除此之外首页不出现任何其他内容（英雄区/今日历练/推荐/任务/搜索/篇目列表全部移除）。闯关地图重做为**手游式画布地图**：关卡节点散布在星空画布上、金色蜿蜒路径连接、S 形蛇形排布、按年级分组为"世界"。篇目唯一入口 = 地图关卡。

## 背景

- 现状：首页 `/` 是"游戏大厅"（HeroStats 英雄区 + 今日历练 + 推荐卡 + 任务卡 + 搜索 + 全部篇目列表），闯关地图在 `/map`（竖向列表式路径）
- 用户反馈（08-13 确认）："整个主页面就只是一个闯关地图，地图做好看，其他不要出现"
- 已确认决策：
  - 创建 Trellis 任务跟踪
  - 首页 = 地图，TabBar 两 tab（地图/成就）
  - 彻底移除搜索/篇目列表，仅地图入口
  - **重做画布式地图**（关卡节点散布星空画布 + 金色蜿蜒路径 + S 形排布，接近手游闯关地图）

## 需求

### R1. 首页 = 画布式闯关地图
- **R1.1** `/` 路由直接渲染闯关地图（LevelMap 重做后作为首页主体），不再渲染 Home（英雄区/今日历练/推荐/任务/搜索/篇目列表全部移除）
- **R1.2** `/map` 重定向到 `/`（旧入口兼容，不 404）
- **R1.3** 地图保持懒加载（LevelMap lazy 独立 chunk，moxie.json 数据按需加载，首屏主 chunk 不含 555KB 数据）

### R2. TabBar 两 tab
- **R2.1** TabBar：**地图(/) / 成就(/achievements)**，移除"历练"tab
- **R2.2** 激活逻辑：`/` 与 `/articles/*`（关卡页）激活"地图"tab；`/achievements` 激活"成就"tab

### R3. 地图重做（画布式）
- **R3.1** 关卡节点**散布在画布上**：按 S 形（蛇形）排布——奇数节点靠左、偶数节点靠右（百分比定位），纵向等距
- **R3.2** 相邻节点用**金色蜿蜒路径连接**（SVG 二次贝塞尔曲线，vector-effect 保线宽），形成连续闯关路径
- **R3.3** 按年级分组为"世界"：每个世界一张星空画布，世界标题（金色）+ 进度（x/y 篇）+ 简短副题
- **R3.4** 节点状态视觉：已通关=金色发光+星标、可玩=翠绿跳动光圈、未解锁=暗色锁；节点显示全局关卡编号
- **R3.5** 地图头部：标题"🗺️ 闯关地图" + 总进度（x/142 已通关）+ "我的成就"入口
- **R3.6** 视觉增强：星空背景（星点/光晕）、世界卡片式半透明底、节点 hover 放大、路径金色渐变发光
- **R3.7** 移动端适配：画布宽度自适应（百分比定位），S 形排布在 375px 下不溢出，节点可点

### R4. 篇目入口收敛
- **R4.1** 篇目唯一入口 = 地图关卡 → 关卡页默诵 tab（`/articles/:id/moxie`）
- **R4.2** `/moxie` 默诵列表页保留（深链可达），但首页无任何入口
- **R4.3** 首页搜索框/全部篇目列表/年级 tab 全部移除（Home 不再渲染）

### R5. 组件清理
- **R5.1** 移除 `Home.tsx` 引用（App.tsx 不再 import）；`home.css` 仅被 Home 使用则一并移除
- **R5.2** `HeroStats.tsx` 无其他引用则移除（或保留文件但不渲染——以 grep 为准）
- **R5.3** 关卡页/其他页面不受影响（ArticlePage 等不动）

### R6. 测试同步
- **R6.1** 三套 playwright 测试同步：browser-test / page-scan / full-flow-test 中首页断言改为"地图首页"（无 .article-card/.today-title/.home-search-box，有 .gx-map/.gx-world/.gx-canvas）
- **R6.2** TabBar 断言改为两 tab（地图/成就）
- **R6.3** `/map` 重定向断言
- **R6.4** 篇目进入路径改为地图关卡点击或直接深链
- **R6.5** page-scan 路由清单同步

## 验收标准

1. 访问 `/` 只见闯关地图：星空画布 + S 形关卡节点 + 金色蜿蜒路径 + 世界分组；无英雄区/今日历练/推荐/任务/搜索框/篇目列表
2. TabBar 仅"地图/成就"两 tab；`/map` 自动跳回 `/`
3. 地图节点状态清晰（通关金/可玩绿/锁定灰），全局关卡编号 + 星级显示
4. 点击任意可玩/已通关关卡 → 关卡页默诵 tab（`/articles/:id/moxie`）
5. 移动端 375px 首页=地图无横向溢出，节点可点
6. 首屏性能：主 chunk 不含 moxie.json 数据（LevelMap lazy 加载）
7. 回归全绿：typecheck + validate + browser-test + page-scan + full-flow-test
8. `npm run build` 通过
9. 部署 Vercel 生产后线上验证：首页=地图、无"学习/默写"字样
