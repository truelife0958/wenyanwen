# 原文默写重写记录 (08-11-moxie-input-fill)

## 数据重写 (scripts/moxie/rewrite-original-moxie.py)

### 规则
1. **全挖句** (句内无保留文字且有逗号): 用答案[0] 在 learning 原文定位 → 保留前分句, 挖后分句; 答案取原文分句 (修正错位)。
2. **部分挖句**: q 与答案原样保留 (不做修正, 避免引入新错误)。
3. **篇级**: 整篇全部为全挖重建且无任何完整句 → 首题首句填满 (至少保留一句)。
4. **标点归一化**: 全量半角标点 → 全角 (q/answers/extra, 3806 字段; qid 排除)。
5. **legacy 合并**: build 时原文默写题型以 book 为准, legacy 零散题丢弃 (避免连续 2 空)。

### 统计
- 全挖重建 78 题、原样 132 题、跳过 7 题 (默写效果检测卷, 无 learning 原文)。
- 首句完整保留 38 篇。
- 人工修正: 子衿 0:2 (答案对齐原文)、水调歌头 0:0/0:1/0:2 (答案错位修正)、别云间 0:0/0:1 (整首错乱重建)。

### 效果示例
- 观沧海: `___, ___。___, ___。...` (12 空, 答案"东临碣石 以观沧海"双分句)
  → `东临碣石，___。水何澹澹，___。...` (5 空, 每空单分句) + 首句完整。
- 次北固山下: `客路青山外, ___。` (保留前分句)。

### validate 段 12 断言
- 原文默写题总数 ≥ 100
- 无多分句答案 (顿号、为合法列举, 排除)
- 无全挖题 (每题含保留文字)

## 交互改造 (MoxieArticle.tsx)

- **原文默写题**: 每个 ___ 渲染为可输入横线 (moxie-blank-input, 虚线底边);
  - 全部填写后可点"对答案" → 自动判分 (normAnswer 忽略标点/空格/全半角)
  - 判对: 绿色态 + "✓ 全部答对"; 判错: 红色态 + 逐空显示 我的答案 → 正确答案 + "重新作答"
  - 答错自动进错题本 (qid/进度存储不变)
- **其他题型**: 保持"对答案 → 自评"流程。
- test:flow 步骤 3/6 适配新交互 (输入→判分→错题入库)。

## 验证

- `npm run check`: 0 错误 (含 validate 段 12)
- `npm run test:flow`: 42/42
- 浏览器实测: 观沧海 6 输入框 → 填"以观沧海"+错 → "答对 1/6" + 错题本 1 条
