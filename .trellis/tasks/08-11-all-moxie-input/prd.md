# 4 类默写输入化 + 词义去重 + 数据全量排查

## Goal

理解性/词义/译文/原文 4 类默写全部改为"横线输入 → 对答案自动判分";修复词义默写重复题(book+legacy 同词并存);拆分多小题题(序号 1.2.3.);全量数据标点/结构/重复排查修复。

## Background (已排查事实)

- runtime 词义默写重复: book `moxie-论语十二章:2:8 知之者不如【好】之者好：___` vs legacy `2:15 知之者不如【好】之者: ___` —— 同词不同 q 格式并存(legacy 合并未按词去重)。
- legacy 词义默写 324 题均带序号(`1. 略无【阙】处: ___`,1 题 1 词);合并时未与 book 按【词】去重。
- legacy 多小题译文题 6 题(q 含 `1. ...译文：___ 2. ...`,answers 用 `|` 或数组多元素分隔)—— 需拆分为独立小题。
- legacy 标点半角残留(上一轮只归一化了 book moxie.json,legacy 未处理)。
- 用户反馈"知之者不如【好】之者: ＿＿＿,标错了" = 2:15 与 2:8 重复且格式不一致(去重后消失)。

## Requirements

### R1. 4 类默写全部输入化 (MoxieArticle.tsx + moxie.css)
- FillQuestionCard 通用化: 原文/理解性/词义/译文 4 类题型统一渲染输入横线(词义题保留【字】高亮, 译文题答案长时输入框自适应)。
- 对答案自动判分(normAnswer 容错标点/空格/全半角)→ 答对绿/答错红 + 显示正确答案 + 答错自动进错题本 + 重新作答。
- 译文默写判分: 归一化后精确比较;答错显示完整参考译文。
- 词义默写: 【字】高亮保留, 释义输入。

### R2. 数据修复 (scripts/moxie/dedup-legacy-moxie.py + build 脚本)
- 词义默写按【词】去重: book 优先, legacy 同词丢弃(保留 legacy 独有词)。
- legacy 多小题译文题拆分为独立小题(answers 数组/`|` 分隔一一对应;缺失答案按句匹配 book 或其他数据, 匹配不到保留原 q 不臆造)。
- legacy 全量标点半角→全角(q/answers/extra)。
- 理解性默写独立题保留序号(出处信息), 不删。

### R3. 全面数据排查 (validate 段 13)
- 词义默写同篇无重复【词】;无多小题 q(拆分彻底);无 `|` 多答案;q/answers 无半角标点。
- 全题型扫描: q 与 answers 空值、answers 含 `___`、q 含换行残留、编号错乱。
- runtime 合并后同篇同题型重复题 = 0(除原文默写已去 legacy)。

### R4. 验证
- check + test:flow 全绿(步骤 3/6 已适配输入, 步骤 6 需验证对非原文题型仍通过)。
- 浏览器实测: 论语十二章词义无重复;译文多小题拆分后独立判分。

## Acceptance Criteria

- [ ] 4 类默写全部输入横线 + 自动判分, 答错自动进错题本
- [ ] 词义默写同篇无重复词(runtime 可证明)
- [ ] legacy 6 题多小题译文拆分为独立小题, 无 `|` 残留
- [ ] validate 段 13 通过;check + test:flow 全绿
- [ ] 修复记录 research/fix-record.md(拆分清单/去重词数/标点修正数)

## Notes

- 不臆造答案: 拆分后答案缺失且无法匹配 → 保留原 q 分行显示 + 记录。
- legacy 序号题是独立题(非多小题), 序号保留。
