# 视觉审查与美化修复

## Goal

用视觉模型对全项目页面做双视口(桌面 1280×900 / 移动 375×812)逐页审查,输出问题清单,实施修复,复审通过。

## Requirements

### R1. 截图采集
- 页面清单: 首页 / 学习页(学习标签) / 学习页(鉴赏标签) / 默写列表 / 默写练习(原文默写题) / 错题本(空态+有数据) / 404。
- 每页 × 桌面/移动双视口截图,存档本任务 research/shots/。

### R2. 视觉模型审查
- 用 `scripts/vision/vision.mjs` 对每张截图 ui-review(或 describe 辅助)。
- 问题维度: 布局对齐 / 间距节奏 / 色彩层次 / 字号层级 / 组件观感(卡片/按钮/徽章/表单) / 响应式(移动端溢出/挤压)。
- 输出分级清单(P1 明显丑/P2 一般/P3 微调),含截图定位。

### R3. 修复
- 按清单修改 CSS(走 tokens.ts,禁硬编码);必要时调整组件结构/文案。
- 修复后重新截图 + 视觉模型复审。

## Acceptance Criteria

- [ ] 截图覆盖全部页面 × 双视口(至少 10 张)
- [ ] 审查清单含每页问题、定位、建议
- [ ] P1 级问题全部修复,复审通过
- [ ] check + test:flow 全绿;validate 段 11 保持绿
