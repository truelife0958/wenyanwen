# 首页信息架构重构 — 去冗余、简洁美观

## 问题（用户反馈）

首页入口重复啰嗦：
1. **同一组入口出现两次**：cat-nav chips（学习课文/综合字词/综合复习/错题本）+ 点分类后出现的 entry 大卡（同样的 4 个入口）— 表达重复
2. "全部篇目"与"学习课文"语义重叠
3. 分类切换逻辑复杂（chips → activeCat → 条件渲染两套内容）

## 现状结构（7 区块，入口 2 处）

```
1. hero 横幅（统计）
2. 搜索栏
3. cat-nav chips（5 个）          ← 入口①
4. home-strip（学习进度）
5. continue-card（继续学习）
6. [仅 all 时] 年级 tab + 篇目网格
7. [仅非 all 时] 4 张 entry 大卡     ← 入口②（重复）
```

## 重构目标（6 区块，单一入口层）

```
1. hero 横幅（统计 + 印章）         — 精简
2. 搜索栏                          — 保留
3. 四入口大卡（唯一入口层）           — 学习课文/综合字词/综合复习/错题本，始终显示
4. home-strip（学习进度）           — 保留
5. continue-card（继续学习）        — 保留
6. 年级 tab + 篇目网格              — 始终显示（无需分类切换）
```

## 关键改动

| 项 | 现状 | 重构 |
|---|---|---|
| cat-nav chips | 5 个，含 4 入口 | **删除**（入口由大卡承担） |
| entry 大卡 | 仅非 all 显示 | **始终显示**（4 张，2×2 或 4 列） |
| activeCat 状态 | chips 切换分类 | **删除**（无分类切换） |
| 学习课文入口 | chips 'learn' | 大卡点击 → 滚动到篇目网格 |
| 错题本入口 | /collections | /collections?err=1（已有定位+高亮） |
| 篇目网格 | 仅 all 显示 | 始终显示（搜索过滤 + 年级 tab） |

## 视觉

- 4 入口大卡：图标块 + 标题 + 描述 + 进度条（现有 entry-card 样式强化）
- 布局：hero 下直接入口卡（一眼看到 4 个功能），再往下是篇目
- 删除 chips 后页面更清爽，无重复导航

## 验收

1. 首页无重复入口（同一功能只有一个入口）
2. 4 入口卡直达正确页面（学习→篇目区/字词→cards/复习→collections/错题→错题区块）
3. 篇目网格始终可见（搜索/年级 tab 正常）
4. check / browser-test / full-flow / page-scan 全绿（断言适配新结构）
