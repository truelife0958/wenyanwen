# 关卡动画讲解 + 横版卷轴世界地图 + 按状态分流跳转

## Goal

三合一改造：1) 每个关卡新增**程序化动画讲解模式**（逐句高亮原文 + 同步译文/注释 + TTS 朗读，纯前端生成，142 关全适用）；2) 闯关地图重构为**横版卷轴世界地图**（蜿蜒路径 + 玩家 Token 沿路径移动 + 路径流动光效 + 节点呼吸/点击高亮，Candy Crush 式）；3) 点击关卡**按状态分流**（未通关→历练 tab，已通关→默诵 tab）。

## 背景

- 现状：点击关卡一律进 `/articles/:id/moxie`（默诵）；地图是竖版 S 形画布（LevelMap 2026-08-13 刚重做）
- 用户反馈（08-13 确认）：
  - 点击每一关，跳转到历练
  - 为每一关生成动画视频讲解
  - 闯关地图画布更好看一些；网络搜索闯关地图画布，重构优化
- 已确认决策：
  - 创建 Trellis 任务跟踪
  - **程序化动画讲解**（逐句高亮 + TTS 朗读 + 译文/注释动画，非真实视频）
  - **横版卷轴世界地图**（Candy Crush 式）
  - **按状态分流**：未通关→历练，已通关→默诵

## 需求

### R1. 点击关卡按状态分流
- **R1.1** 地图节点点击：**已通关**（passed）→ `/articles/:id/moxie`（默诵）；**可玩未通关**（unlocked）→ `/articles/:id/learn`（历练）
- **R1.2** 锁定节点不可点（保持现状）

### R2. 程序化动画讲解模式（核心新功能）
- **R2.1** 关卡页历练 tab 提供"▶ 动画讲解"入口（ArticleReader 顶部按钮）
- **R2.2** 讲解模式（全屏覆盖层/独立视图）：
  - **逐句推进**：原文按句切分（复用 splitSentences），当前句高亮（金色下划线/背景），随进度滚动定位
  - **同步译文**：当前句对应译文在下方同步显示
  - **TTS 朗读**：调用现有 `speak()`，朗读当前句；onBoundary 驱动字级高亮（可选）；句完自动进下句
  - **注释**：当前句涉及的字词注释（可选，GlossPop 数据）展示
- **R2.3** 播放控制：播放/暂停、上一句/下一句、进度条（第 n/总句）、关闭
- **R2.4** 语速调节（复用现有 read-tools 语速）；不支持 TTS 时仍可手动逐句浏览（静音模式）
- **R2.5** 动画观感：句句过渡动画（fade/slide）、高亮流动、进度条随朗读推进、结束时"本关讲解完毕"提示
- **R2.6** 数据驱动：全部 142 关通用（article.reading.paragraphs 原文+译文）

### R3. 横版卷轴世界地图（重构 LevelMap）
- **R3.1** 地图画布改为**横向卷轴**：世界（年级）横向并排，容器 `overflow-x` 滚动
- **R3.2** 每世界内部：节点沿蜿蜒路径排布（纵向小 S 形或紧凑蛇形），相邻节点金色弯曲路径连接
- **R3.3** 世界头部：标题 + 进度 + 图标；世界间由"通行桥"连接线衔接
- **R3.4** 玩家 Token：发光徽标定位在当前可玩/最近通关节点，进入地图时**平滑滚动到玩家位置**
- **R3.5** 路径动效：金色路径**流动光效**（SVG stroke-dashoffset 循环动画），可玩节点**呼吸光晕**，节点点击高亮反馈
- **R3.6** 节点状态保持 4 态：锁定/可玩/已通关(星级)/玩家当前位置
- **R3.7** 世界导航：顶部世界快捷条（点击滚动到对应世界）
- **R3.8** 移动端：横向触摸滑动 + 点击节点 44px+ 触控区 + 无横向溢出（滚动容器内滚动，不撑破页面）
- **R3.9** 视觉：星空背景分层（远景星云/中景路径/玩法节点），世界卡片式区域，金色主题

### R4. 测试同步
- **R4.1** 三套测试同步：地图节点分流断言（通关→moxie / 未通关→learn）、讲解模式入口与逐句推进断言、横版地图结构断言（.gx-canvas-h 横向滚动容器/世界并排/玩家 token）
- **R4.2** page-scan 路由清单 + 移动端无溢出（滚动容器内不溢出）
- **R4.3** 讲解模式 TTS 在 headless 环境不支持时的降级断言（静音逐句可用）

## 验收标准

1. 点击未通关关卡 → 关卡页**历练 tab**（`/articles/:id/learn`）；点击已通关关卡 → 默诵 tab
2. 关卡页历练 tab 有"动画讲解"入口；进入后逐句高亮原文 + 同步译文 + 朗读推进，播放/暂停/上下句/进度条/关闭齐全；不支持 TTS 时可静音逐句浏览
3. 地图为**横版卷轴**：世界横向并排、横向滚动；玩家 Token 定位当前位置并自动滚动到；路径流动光效 + 节点呼吸 + 点击高亮
4. 移动端：横向滚动在容器内（页面不横向溢出），节点可点（≥44px）
5. 回归全绿：typecheck + validate + browser-test + page-scan + full-flow-test
6. `npm run build` 通过
7. 部署 Vercel 后线上验证：分流跳转、讲解模式、横版地图
