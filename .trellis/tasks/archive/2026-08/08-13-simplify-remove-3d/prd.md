# 做减法回简洁: 移除全站 3D 粒子 + 精简讲解模式

## Goal

用户反馈"项目越做越拉垮"（卡顿性能/讲解冗长/视觉不协调/整体杂乱）。执行减法重构：**移除全站 three.js 3D 粒子背景**（卡顿与杂乱主因），**讲解模式精简**（流程回归纯句子，字词/重点句改为内联增强不占步骤），全站视觉回归统一协调的新中式（深色地图页 + 浅色阅读页）。

## 背景

- 用户在**线上**看到问题，反馈四类：卡顿性能、讲解模式太冗长（49 步）、视觉不协调、整体杂乱
- 已确认决策：**做减法，回到简洁**（内容为王，稳定可靠）
- 现状：
  - 全站 `InkScene`（three.js 3D 水墨粒子）挂载于 App，所有页面渲染粒子 → 卡顿 + 浅色页干扰 + 视觉杂乱
  - 讲解模式五段式把字词卡(13)/重点句卡(6)/鉴赏卡(9)插入流程 → 49 步太长
  - three.js 依赖 708K chunk 懒加载

## 需求

### R1. 移除全站 3D 粒子（核心减法）
- **R1.1** App.tsx 移除 `<InkScene />` 全局挂载
- **R1.2** 删除 `src/features/ink/`（InkScene.tsx / ink.css）及引用（LectureMode 的 inkBurst）
- **R1.3** 移除 three.js / @types/three 依赖（package.json + lockfile）
- **R1.4** 背景回归：深色页（地图/成就）保留现有 .gx-sky 静态墨青渐变 + 星点（无粒子动画）；浅色页（阅读/训练）干净米白
- **R1.5** 讲解模式深色界面：保留墨青底 + 哑金样式（无粒子），干净聚焦

### R2. 讲解模式精简
- **R2.1** 流程步骤 = **纯句子**（不再把字词/重点句/鉴赏插成独立步骤）
- **R2.2** 当前句若有重点字词：在句下方显示**内联小卡**（word + 释义，不占步骤、不打断流程）
- **R2.3** 当前句若是重点句（背诵句）：句上加"重点句"小徽章 + 译文下方提示
- **R2.4** 段鉴赏：段结束后以**内联小字**展示（折叠式/简短），不占步骤
- **R2.5** 末尾保留**一个**随堂练习卡（可跳过），非词义题真题
- **R2.6** 进度条 = 句子数（岳阳楼记 20 步左右），简洁

### R3. 视觉协调回归
- **R3.1** 全站无粒子动画后，深色页（地图/成就/讲解）与浅色页（阅读/默诵）层级清晰、不互相干扰
- **R3.2** 移除 ink 相关残留样式/类
- **R3.3** 检查并清理因粒子引入的 z-index/层级（.app-shell z-index 等可还原）

### R4. 性能与验证
- **R4.1** 移除 three 后：主包更小、无 rAF 常驻渲染、无 WebGL 负担
- **R4.2** 回归全绿：typecheck + validate + browser-test + page-scan + full-flow-test
- **R4.3** 测试同步：移除 3D canvas 断言，讲解模式断言改为精简版（句子 + 内联字词卡 + 练习卡）
- **R4.4** `npm run build` 无 three chunk，首屏更轻
- **R4.5** 截图目检：地图（静态墨青无粒子）/浅色页（干净）/讲解模式（简洁聚焦）

## 验收标准

1. 全站无 three.js 3D 粒子（无 canvas、无 rAF 常驻、无 three chunk）
2. 讲解模式流程 = 纯句子（20 步级），字词/重点句为内联增强，练习末尾单卡
3. 浅色阅读页完全干净无粒子干扰；深色页静态墨青雅致
4. 回归全绿（typecheck/validate/87/101/48）+ build 无 three
5. 部署后线上验证：流畅、简洁、协调
