# 默写书全量抽取 + 应用改造（学习/默写双模块）

## Goal

将《2026初中语文•一本必背文言文+古诗默写》（主书 120 页 + 答案册 33 页，扫描版 PDF）四种默写题型（原文默写/理解性默写/词义默写/译文默写，126 篇）**全量、无遗漏**抽取并集成到应用。同时按用户决定将应用收窄为 **学习 + 默写练习** 双模块：移除字词卡片、考点图谱、背诵卡；现有非默写试题经 AI 识别转换为固定 4 步题型；错题本并入默写模块；学习模块四项打磨（阅读体验/对照朗读/内容深化/学练联动）。

## Requirements

### R1 默写数据全量抽取（无遗漏）
- R1.1 主书正文 117 页（PDF p004–p120）逐页抽取，覆盖全部 **126 篇课文 × 4 种题型**（原文默写、理解性默写、词义默写、译文默写），每页全部题目、全部填空不得遗漏。
- R1.2 答案册 32 页答案（PDF p002–p033）逐页抽取，按篇目分组，与主书题目**一一配对**（题型+序号+题干特征），多空题用 `|` 分隔。
- R1.3 特殊章节一并抽取：
  - 目录中标注的 **默写效果检测**（独立章节，书页 57 起）
  - **课标补充篇目**（书末）
  - **附录：主题默写**
- R1.4 完整性校验（页级）：主书 117/117 页有抽取结果、126/126 篇覆盖、每篇 4 题型齐全、答案配对率 100%。
- R1.5 题目原文逐字保留：填空统一 `___`、加点字 `【】`、选项 A/B/C/D、中考来源标注（如"（四川绵阳中考）"）不丢失。

### R2 旧非默写数据 AI 转换
- R2.1 现有非默写数据（practice 一文一练 307 题、zhenti 真题 1585 题、exam 考点题）经 AI 识别转换为固定 4 步题型（原文/理解性/词义/译文默写），归类到对应篇目。
- R2.2 与默写书抽取结果合并：重复题去重（保留默写书版本），旧数据仅作补充题源。
- R2.3 转换结果同样进入默写练习题库，题源字段（moxie 书/旧数据转换）可区分。

### R3 应用改造（学习 + 默写双模块）
- R3.1 首页仅 2 卡：**学习**（现有 learning 课文全解，127 篇）与**默写**（新模块）。
- R3.2 移除：字词卡片（flashcard）、考点图谱（ExamMap）、背诵卡（recite）、旧练习（passage 一文一练）入口；对应 runtime 数据不再打包。
- R3.3 错题本保留并**并入默写模块**（默写错题记录 + 复习），学习模块不涉及。
- R3.4 默写模块功能：
  - 按年级/篇目浏览 4 种题型
  - 练习模式：出题 → 作答（填空输入/选择题）→ 自评对答案
  - 错题自动进错题本，支持重练
  - 学练联动：学习页某篇直接"去默写"，默写页可跳回学习页看原文/译文
- R3.5 学习模块打磨（四项全做）：
  - 阅读体验：排版、字号、主题、夜间模式、阅读进度记忆
  - 对照与朗读：原文/译文/注释对照、TTS 朗读（语速/跟读）
  - 内容深化：段落分析、精要、考点标注补全
  - 学练联动：学习 → 默写跳转与进度贯穿

### R4 数据管道
- R4.1 抽取产物落盘为可复现 JSON（`ocr/moxie/*.json` 或等效目录），与手写/生成数据分离。
- R4.2 `scripts/build-runtime-data.mjs` 扩展：raw 数据（learning + moxie 默写）→ runtime 数据，`data:build` 可复现。
- R4.3 移除的模块数据不进 runtime 包。

- [ ] 答案册全量抽取完成，校验脚本确认：按篇配对率 100%，多空题答案完整。

- [ ] 应用构建通过（`npm run check`）：首页仅 学习/默写 2 卡；flashcard/ExamMap/recite/passage 入口与相关 runtime 数据移除。
