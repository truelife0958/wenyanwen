# 数据审核与 CSS 精修

## Goal

两个交付物:
1. **数据审核**: 全量程序化扫描(126 篇文章、2144 词条/2495 词义、2022 题、16 题集)+ 重点篇目人工抽审,产出数据准确性报告;发现缺陷立即修复(数据管道可修则修,OCR 级缺陷记录)。
2. **CSS 精修**: 保留现有"书卷纸墨"风格与布局骨架,统一设计令牌、修复样式不协调、补齐动效过渡(页面切换/卡片悬浮/进度条/骨架屏/按钮反馈),让界面简洁美观、适合初三学生产生学习兴趣。

## Requirements

### R1 数据审核(全量程序化 + 抽审)
- **程序化全量扫描**(写一次性审核脚本,不修改数据):
  - 文章层: 标题/作者/朝代/年级合法性;原文标点异常(连续标点、缺失句读);原文 vs 译文段落数对齐;译文含原文残留(未翻译片段);背诵句(stars)在原文中可定位。
  - 字词层: 义项含原文词?释义异常短(<2字)或异常长;category 枚举合法性;example 是否能在对应文章原文中定位(抽查)。
  - 题目层: 题干含答案泄漏(题干文本包含答案文本);选择题 options 数量合法性(2-6);答案不在 options 中(选择题);type 与 options/answer 形态一致性;译文题答案长度异常。
  - 引用层: 已由 validate 覆盖,重点复扫。
- **人工抽审**: 抽取 6 篇重点篇目(论语十二章、岳阳楼记、出师表、桃花源记、三峡、陈涉世家)逐条核读原文/译文/注释/赏析,记录发现。
- 审核发现的问题: 程序化可修(管道/数据文件)→ 修复;内容争议/OCR 级 → 记录报告。
- 产出 `data-audit-report.md` 到任务目录。

### R2 CSS 精修(现有风格 + 动效)
- **设计令牌统一**: 审查 `src/shared/styles/tokens.ts` 与各 CSS 文件,找出硬编码颜色/圆角/阴影/间距,收敛到令牌。
- **布局与视觉协调**: 检查各页面(首页/学习/练习/字词卡/错题本/图谱)标题层级、卡片间距、字体大小节奏、色彩对比度(浅色主题 WCAG 4.5:1 抽查)。
- **动效补齐**(尊重 prefers-reduced-motion):
  - 页面切换过渡(view-enter 已有,统一节奏与缓动)
  - 卡片悬浮(article-card/entry-card 微抬升 + 阴影)
  - 按钮反馈(press 状态)
  - 进度条动画(练习/背诵/统计环)
  - 骨架屏(已有,检查一致)
  - 注释浮层/弹窗出现动画
  - 错题/判分结果反馈(✓/✗ 出现动画)
- **移动端**: 375px 无溢出回归(page-scan 验证)。
- **初三学生兴趣导向**: 适度活泼(徽章/进度环/完成动效),但不喧宾夺主。

### 验收标准
- [ ] 数据审核脚本输出全量扫描结果(0 缺陷或缺陷清单定性),报告落盘。
- [ ] 抽审 6 篇重点篇目完成,发现记录。
- [ ] 数据缺陷修复后 `npm run check` 通过;无法修复的 OCR 级缺陷记录。
- [ ] CSS 重构后 tokens 无硬编码色值残留(或残留清单 < 5 处并定性)。
- [ ] 动效齐备且尊重 `prefers-reduced-motion`。
- [ ] `npm run check` + `npm run test:flow`(46 项)+ `node scripts/page-scan.mjs`(77 项)全部通过。
- [ ] 视觉抽查: 用 vision 脚本截图首页/学习/练习/字词卡前后对比,记录改善。
