## 2. 发现并修复的缺陷

### 2.1 practice:115 答案格式错误(已修复, ERROR 级)
- 位置: `src/data/raw/practice.json`(穿井得一人)
- 问题: 选择题选项为 ①②③④ 圈号,答案 `"③"`。前端判定用字母 A-D,该题**永远判错**。
- 修复: answer `"③"` → `"C"`(第 3 个选项)。

### 2.2 37 道 choice 题缺 options 字段(已修复, ERROR 级)
- 问题: 39 道 `type: choice` 题在 raw 数据中无 `options` 字段(选项文本内嵌在题干 A./B./甲: 格式中),前端将其当主观题处理,用户看不到选项按钮。
- 修复: `scripts/build-runtime-data.mjs` 管道新增 `extractOptionsFromStem()` + `normalizeChoiceAnswer()`:
  - 从题干提取 A-D 或甲乙丙格式选项填充 options
  - 答案 "A。解析…" → "A"、"丙（正确）…" → "C"
- 效果: 选择题 108 → **145 道**,37 道恢复为真正的选项选择交互。
- 剩余 2 条(zhenti:823/860): raw 抓取数据中选项文本确实缺失(823 题干无任何选项标记;860 只有【丙】一段),无法自动恢复 → 记录,前端按主观题展示(题干自含可读内容,不影响作答)。
