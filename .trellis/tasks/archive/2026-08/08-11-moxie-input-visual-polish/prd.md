# 默写体验改造 + 全页面视觉美化

## Goal

解决两个问题:① 全页面(桌面+移动双视口)视觉审查与美化——用户反馈"现在太丑了";② 原文默写题改造——每句挖一半(保留另一半)、去掉双分句答案(不要2空)、横线处可直接输入答案并自动判分。

## Background

- 用户已在浏览器查看项目(dev server 运行中),反馈整体观感差。
- 原文默写现状:166 题多空(blanks>1),如观沧海整首 12 空,answers 形如 `东临碣石 以观沧海`(双分句合一个答案,即"2空")。
- 交互现状:点"对答案"→ 显示答案 → 自评(答对/答错)→ 答错进错题本;无输入功能。
- 视觉审查工具: `scripts/vision/vision.mjs`(本地视觉大模型,支持 url/截图文件,ui-review/describe 模式,桌面/移动视口)。

## Requirements

### R1. 全页面视觉审查与美化 (子任务 08-11-visual-audit-fix)
- 逐页截图(桌面 1280×900 + 移动 375×812): 首页 / 学习页(学习/鉴赏标签) / 默写列表 / 默写练习 / 错题本 / 404 兜底。
- 视觉模型逐图审查(ui-review),输出问题清单(间距/对齐/层次/色彩/字号/组件观感)。
- 按清单实施修复(样式层,走 tokens.ts 令牌体系)。
- 复审: 修复后再次截图+视觉模型确认,问题清零或记录遗留。

### R2. 原文默写改造 (子任务 08-11-moxie-input-fill)
- **数据改造**: 原文默写题重写——每句(对句)挖一个分句,保留另一半;每空答案=单分句(去双空);原 q/answers/blanks 同步更新;至少保留完整句(整篇不挖空的比例合理,每篇保留 ≥1 完整句)。
- **交互改造**: 横线(___)处为可输入框,用户填写答案;点"对答案"自动比对(容错:忽略首尾空格、标点差异、全半角);判对显示成功态、判错显示参考答案并自动进错题本;进度/错题本 qid 兼容(不改变 qid 结构)。
- 其他题型(理解性/词义/译文默写)交互保持一致(可输入或保持现状,以设计为准)。

## Constraints

- qid 结构不变(`moxie-{title}:{sec}:{i}`),既有进度兼容。
- 数据改造保留原文准确性:重写基于 learning.json 原文或现有答案,不引入新错字。
- 样式修复走 tokens.ts,不引入新硬编码(validate 段 11 gate 保持绿)。
- `npm run check` + `npm run test:flow` 全绿;test:flow 中默写流程断言需同步更新(如有)。

## Acceptance Criteria (跨子任务)

- [x] 视觉审查覆盖全部页面 × 双视口,修复后复审无 P1+ 级问题
- [x] 原文默写题:无双分句答案(answers 每项=单分句);每句保留一个分句;每篇至少 1 完整句保留
- [x] 默写题横线可输入,对答案自动判分(容错标点),答错自动进错题本
- [x] validate 新增原文默写题数据断言(无 2 空/保留句比例)且通过
- [x] check + test:flow 全绿
