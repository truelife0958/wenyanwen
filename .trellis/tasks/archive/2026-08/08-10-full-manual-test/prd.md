# 逐项功能测试

## Goal

打开项目,启动 dev server,逐项测试**每一个功能细节**——不只跑既有自动化测试,而是补充浏览器实测:每个路由、每个 tab、每个交互状态、数据渲染细节、移动端适配、PWA 行为、错误边界。任何异常(渲染错误、交互失效、样式错乱、数据缺失)都记录并修复。

## Requirements

### R1 测试准备
- 启动 dev server,确认可访问。
- 跑基线: `npm run check`(快)+ 既有 `test:flow` + `page-scan` 确认无回归。

### R2 逐项测试清单(全部浏览器实测)

#### 2.1 首页 (/)
- 标题/统计信息正确(126 篇 · 词义 · 题数)
- 搜索: 按篇名/作者/朝代搜索、清空按钮、无结果空态
- 年级 tab: 6 个年级切换、计数徽章、选中态
- 篇目卡片: 中考必考/核心重点徽章、悬浮/按压动效、长标题不重叠
- 今日学习: 背诵进度环百分比、继续学习横幅跳转、弱项推荐跳转
- 错题本入口卡: 计数、进度条、点击跳转
- 今日任务: 学习/练题/背课文状态
- 底部 TabBar: 学习/字词/图谱 三 tab 激活态

#### 2.2 学习页 (/articles/:id)
- 三个 tab: 学习/鉴赏/练习 切换与 URL
- 原文渲染: 段落、圈号注释角标、多字重点词标注、整句翻译(key-sent ★)
- 注释交互: 点击词弹出浮层(位置/内容)、Esc/点击关闭、hover 延迟关闭
- 译文展开/收起
- 朗读: 播放/停止、高亮跟随、朗读设置
- 注释清单、赏析清单
- 无效文章 id → 重定向
- 旧链接 /learning/:title /practice/:title 跳转

#### 2.3 练习页
- 单题流: 上一题/下一题、进度条、提交判分
- 选择题: 单选/多选(ABD)、判分对错动画、选项禁用
- 主观题: 自评(对/错)、未作答提示
- 结果页: 正确率、错题列表、错题入本、再练一次、查看错题
- 新恢复的 37 道选项提取题: 抽查 3 道渲染选项正常

#### 2.4 字词卡 (/cards)
- 实词/虚词 tab、计数
- 词条弹窗: 义项/例句展开、关闭
- 背诵模式: 翻卡、记住/不熟、进度、完成庆祝
- 词条列表滚动

#### 2.5 考点图谱 (/map)
- 考点分类、高频过滤、薄弱回炉
- 考点弹窗做题、关闭
- URL 参数 ?p= 深链

#### 2.6 错题本 (/errors)
- 空态、分组、移除单条/整组、清空
- 错题数据持久化(localStorage)

#### 2.7 移动端 (375px)
- 首页/学习/练习/字词/图谱/错题 无溢出、可滚动

#### 2.8 PWA 与部署
- SW 注册、离线加载
- 深链 404 恢复

#### 2.9 边界与错误
- 控制台无 error/warning
- 快速点击/连点不崩
- localStorage 损坏兜底

### R3 修复
测试中发现的问题 → 修复 → 复测通过。无法修复的(外部依赖)记录。

## Acceptance Criteria

- [ ] 全部测试项有实测记录(通过/失败/修复),存 `research/test-log.md`。
- [ ] 发现的问题全部修复或定性记录。
- [ ] 复测通过: `npm run check` + `test:flow` + `page-scan`。
- [ ] 无未决的控制台错误。
