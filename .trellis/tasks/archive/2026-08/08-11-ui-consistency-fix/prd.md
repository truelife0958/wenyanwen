# UI 一致性修复: 8类视觉建议

## Goal

修复 2026-08-11 完整视觉回归（vision_chat 28 页审查）发现的 8 类跨页面 UI 一致性问题，统一组件视觉语言，消除视觉模型反复报告的一致性问题，同时保持既有高对比度设计（对比度红线不放松）。

## Requirements

基于视觉回归报告与代码/DOM 实测核实后的真实问题清单（实测排除误报项）：

1. **底部"学习/默写"TabBar 选中态与图标** — TabBar 选中态红底白字为刻意高对比设计（保留），但需确认未选中项对比度足够、图标语义清晰（book/pencil）。实测：选中态白字红底已达标；本项主要验证不误伤，无需大改。
2. **篇目工作区标签（workspace-tabs）选中态反馈弱** — 实测选中项仅红色文字+2px 红下划线，无背景色、无加粗，与"年级标签/底部 Tab"的红底白字风格不一致。改进：选中项加浅色背景（primary-soft）+ 加粗，或统一为红底白字胶囊。
3. **返回链接无按钮样式** — `page-header-back` 纯文字浅色（ink-light），多处（篇目页/默写错题本/旧深链）被视觉模型标注"易被忽略"。改进：加箭头图标/悬停反馈/按钮化，提升可点击性感知。
4. **顶部副标题字小色浅** — `app-header-info`（0.7rem）与 `page-header-meta`（0.86rem ink-light）被多页标注"不易阅读"。适度加大/加深，保持次级信息层级（不得喧宾夺主）。
5. **年级标签选中态视觉跳跃** — `grade-tab.active` 红底白字+红色阴影。保持红底白字（对比度红线），弱化 box-shadow 过强的跳跃感；统一选中/未选中间距。
6. **徽章视觉语言不统一（含真实 bug）** — 已确认 **篇目页标题徽章 `ac-badge-must`/`ac-badge-core` 类无背景色**（global.css 误标死代码但 ArticlePage.tsx 仍在使用）。需：恢复篇目页徽章背景样式；统一"中考必考/核心重点/考点"徽章配色语义（must=红、core=棕/赭、普通=描边），首页/篇目页/考点页使用同一色值体系。
7. **卡片高度一致性** — 实测桌面/移动 12 张卡片高度全部 70px 一致，视觉报告"高度不齐"为误报（旧截图）。验收项：回归确认，无需改动；可顺手将 `.ac-meta` 两行换行保留（信息不截断是刻意设计）。
8. **篇目页标题 meta 信息堆叠** — `朝代 · 作者 · 年级` 用 ` · ` 连接无视觉分隔。改进：增加分隔符样式/合理间距，移动端可换行。

## Acceptance Criteria

- [ ] `workspace-tabs` 选中项有明确的选中态（背景色或加粗），与未选中项对比清晰；移动端横滑可用
- [ ] `page-header-back` 返回链接有可点击性视觉反馈（箭头/悬停/按钮化）
- [ ] `app-header-info` / `page-header-meta` 副标题字号/颜色提升后可读（对比度达标，不抢主标题）
- [ ] 年级标签选中态红底白字保留（对比度不放松），阴影/间距统一
- [ ] 篇目页"中考必考/核心考点"徽章有背景色，与首页/考点页徽章配色语义统一（must=红系、core=棕系）
- [ ] 篇目页标题 meta 分隔清晰，移动端不挤堆
- [ ] TabBar 选中/未选中对比度达标（回归验证）
- [ ] 卡片高度网格一致（回归确认）
- [ ] `npm run typecheck` 通过
- [ ] `node scripts/page-scan.mjs` 全绿（85 项）
- [ ] `node scripts/browser-test.mjs` 全绿（67 项）
- [ ] `node scripts/full-flow-test.mjs` 全绿（44 项）
- [ ] CSS 颜色全部使用 tokens.ts 令牌，无硬编码 hex（validate 段11 gate）
- [ ] 视觉回归复查：修复后重新截图，视觉模型不再报告上述问题
