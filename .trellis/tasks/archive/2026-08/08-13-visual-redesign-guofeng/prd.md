# 全站视觉重构: 新中式·古风雅致设计系统

## Goal

用户反馈整体太丑（"惨不忍睹"）。将全站重构为**新中式·古风雅致**风格：深色雅致底 + 黛青/哑金/米白古典色，竹简/水墨/印章元素，柔光不刺眼，去掉顶部红色横幅改墨色页头。全站页面统一设计语言。

## 背景

- 视觉诊断（AI 设计师审查 2026-08-13）：
  - 荧光绿关卡节点（#3dd6b0）刺眼廉价、发光锯齿生硬
  - 顶部红色渐变横幅 + 底部红色导航"上下夹击"（#c4453c 饱和红）
  - 金色连线（#f5c542）生硬无层次
  - 字体混搭（标题衬线/正文无衬线）、字号层级混乱
  - 布局拥挤无留白、卡片间距不均
  - 图标/边框粗糙、缺少古风文化元素（竹简/水墨/印章）
  - 讲解模式/成就页深蓝紫底（#0b1026）偏"霓虹"
- 已确认决策：
  - **新中式·古风雅致**（深色雅致 + 黛青/金褐/米白，竹简水墨印章，柔光）
  - **全站视觉重构**（统一设计语言）
  - **去掉红色块，改墨色页头**
  - 创建 Trellis 任务

## 需求

### R1. 设计系统（核心）
- **R1.1 色板**：游戏层（game.css --gx-*）与全局（tokens.ts）统一为新中式古典色：
  - 深底：墨青黑（去蓝紫荧光）；黛青（青瓷，取代荧光绿）；哑金（低饱和，取代荧光金）；朱砂（印章红，少量点缀）；米白/墨色文字
- **R1.2 字体**：全站统一衬线（Noto Serif SC 系），标题可加书法感；建立字号层级（标题>章节>关卡>题数）
- **R1.3 光效**：发光柔和羽化（更宽的 blur + 低透明度），去掉锯齿/霓虹感
- **R1.4 元素**：印章（朱砂方章"文"）、竹简纹理、水墨点缀、柔化边框（内阴影/半透明描边）

### R2. 墨色页头（去红色块）
- **R2.1** `.app-header`：红色渐变 → **墨青深色渐变**（#1a1d26→#12151c）+ 金色细线分隔 + 印章 logo（朱砂印章"文"字）+ 米白文字
- **R2.2** 页头信息（N 篇篇章·M 篇默诵）颜色调整（米白半透明）

### R3. TabBar 去红
- **R3.1** `.tab-item.active`：红底白字 → **黛青/墨色底 + 米白字**，或金褐描边胶囊
- **R3.2** hover 态同步调整（去红）

### R4. 游戏层配色（game.css）
- **R4.1** `--gx-*` 全套色板替换（bg-deep/bg-mid/gold/gold-bright/gold-dim/ink/ink-dim/jade/star/fire/ring/mtn）
- **R4.2** 节点：`.playable` 荧光绿→青瓷（柔光）、`.done` 荧光金→哑金、`.locked` 墨灰；发光羽化
- **R4.3** 路径：`gx-path-main/flow/glow` 哑金柔化、流动光效降透明度
- **R4.4** 玩家旗帜、世界列卡片、导航按钮同步

### R5. 讲解模式/成就墙（跟随色板）
- **R5.1** `.lec-*`（讲解模式）：深底去蓝紫、金色哑光、高亮柔化
- **R5.2** 成就墙（.gx-ach-*）：卡片/徽章配色同步

### R6. 关卡页（article.css）
- **R6.1** 篇目标题区：红底"中考必考"标签→印章/金褐底；朗读按钮去红
- **R6.2** 正文注音背景块柔化、段落间距改善（留白）
- **R6.3** 五 tab 选中态、讲解入口按钮配色同步

### R7. 测试与验证
- **R7.1** 回归全绿：typecheck + validate + browser-test + page-scan + full-flow-test
- **R7.2** validate 段 11 CSS 无硬编码 hex（新色必须进 tokens.ts 或 --gx-* 令牌）
- **R7.3** 截图目检各页面（地图/关卡页/讲解/默诵/成就/导航），确认无刺眼元素
- **R7.4** 首屏 chunk 不含 moxie 数据（性能不退化）

## 验收标准

1. 顶部为**墨色页头**（无红色横幅），带印章 logo，全局无大红色块
2. TabBar 选中态无红色（黛青/墨底）
3. 地图节点：青瓷可玩/哑金通关/墨灰锁定，发光柔和无霓虹感
4. 全站色彩统一（无荧光绿/荧光金/蓝紫霓虹残留）
5. 讲解模式/成就墙/关卡页配色与设计系统一致
6. 回归全绿（typecheck/validate/80/101/48）
7. `npm run build` 通过，部署后线上验证
