# 设计方案 — 以孩子体验为中心的重设计

> 目标用户：武汉初三学生（中考备考）
> 核心诉求：**让孩子愿意打开、愿意学、学得进去、学得有成就感**
> 本方案先评审，确认后实现。

---

## 一、问题诊断（为什么现在不满意）

| 现状 | 问题 | 孩子的感受 |
|---|---|---|
| 首页 = 功能大厅（hero+搜索+3入口卡+进度+篇目网格） | 决策负担重，5 种选择 | "打开不知道干嘛" |
| 纸墨视觉反复微调仍不统一 | 细节粗糙、暗红压迫感 | "看着累、不精致" |
| 入口层次多：首页→入口→列表→页面 | 找东西费劲 | "找不着北" |
| 练习/字词/背诵分散各处 | 学习不连贯 | "学完一段要跳来跳去" |
| 内容长段分析堆砌 | 信息过载 | "看不下去" |

## 二、设计理念：**一本"今日学习手册"，不是"功能大厅"**

孩子打开 App 只有一个任务：**"今天学什么"**。App 替孩子决定，孩子只需跟着学。

### 三条核心原则

1. **零决策**：首页不给一堆入口，直接给出"今天学这篇"（继续上次 / 新推荐），打开即学
2. **单任务流**：学习 = 原文沉浸流，练习/字词/背诵全部在原文上下文内完成（不跳出）
3. **看得见的成长**：连续学习天数、进度环、学完即反馈 —— 让孩子有坚持的动力和成就感

## 三、信息架构（页面地图）

```
┌─────────────────────────────────────────┐

│  ┌───────────────────────────────────┐  │
│  │  👋 晚上好，小杰                     │  │
│  │  🔥 已连续学习 5 天                  │  │
│  │  ┌─────────────────────────────┐  │  │
│  │  │  📖 今日推荐：岳阳楼记         │  │  │
│  │  │  继续上次：第 2 段 · 学过 60%   │  │  │
│  │  │  [ 开始学习 → ]               │  │  │
│  │  └─────────────────────────────┘  │  │

│  │  今日任务：读 1 篇 · 记 10 词 · 练 5 题 │  │

│  [ 学习 ] [ 字词 ] [ 我的 ]   ← 底部 3 tab │

```

**底部 3 Tab（移动优先，全站一致）**：
| Tab | 内容 |
|---|---|
| **学习** | 今日推荐 + 篇目列表（按年级，简洁） |
| **字词** | 每日 10 词（新词+到期复习）+ 背诵入口 |
| **我的** | 学习数据 + 错题本 + 设置 |

**学习页（单任务流）**：
```
岳阳楼记（七上）
┌────────────────────────────┐
│ 原文（沉浸阅读，当前段高亮）  │
│  庆历四年春，滕子京谪守巴陵郡…  │
│    ▸ 译：宋仁宗庆历四年春天…   │
│  予观夫巴陵胜状…             │
│    ★背：先天下之忧而忧…      │
│    ✏练：范仲淹表达的思想…     │
├────────────────────────────┤
│ [已学完，完成本课 → 获得 ✓]   │
└────────────────────────────┘
```

**字词页（每日小批量）**：
```
今天 10 个词
[ 之 ] 结构助词「的」        ← 卡片
[ 属 ] 通"嘱"，嘱托
学完 → 🔥 连续 +1 天 · 已记 356 词
```

## 四、视觉系统：**现代友好的纸墨**

| 项 | 现在 | 新设计 |
|---|---|---|
| 底色 | 米色 #f6f2e9 | 更亮暖白 #faf7f0 + 大留白 |
| 主色 | 暗红 #9c2a2a（压迫） | 温暖朱红 #c4453c（友好） |
| 点缀 | 古铜金 | 淡金 #d4a855 |
| 圆角 | 12-16px | 16-20px（更圆润） |
| 卡片 | 细边框+阴影 | 轻阴影 + 无边框（更清爽） |
| 字体 | 通篇宋体 | 标题宋体/正文更清晰的字阶 |
| 动效 | 已克制 | 保留，轻快友好 |

**关键词：明亮、圆润、留白、克制** —— 像一本排版精良的练习册，而不是深色古籍。

## 五、孩子体验设计（关键）

1. **连续学习打卡**：🔥 天数可视化（首屏可见）
2. **进度环**：整课/整学期进度圆环，完成有 ✓ 动画
3. **今日任务清单**：3 个小任务（读/记/练），完成打勾 —— 每天 15 分钟即可
4. **即学即反馈**：背完一句有"记住了 +1"；练完一题有对/错反馈
5. **不吓人**：字词每天只推 10 个；练习量小步快跑
6. **无广告无打扰**：纯净学习

## 六、内容质量改进

| 项 | 问题 | 方案 |
|---|---|---|
| 译文 | 部分段落无译文 | 全篇逐段补齐译文（逐句对照） |
| 注释 | 长段分析堆砌 | 注释精炼为"字义+一句点拨" |
| 题目 | 部分题干冗长 | 小题分行走查、题干精简 |
| 背诵句 | 部分无译文 | 全部补译文 |
| 数据 | 字词释义偶尔重复 | 全库去重复查 |

## 七、实施路线（确认后）

| 阶段 | 内容 |
|---|---|
| P1 | 视觉系统落地（新配色/圆角/留白）— 全站样式刷新 |
| P2 | 首页重构为「今日学习」（推荐卡+进度环+今日任务） |
| P3 | 底部 3 Tab 导航（学习/字词/我的） |
| P4 | 字词页每日小批量 + 打卡 |
| P5 | 内容质量批量修补（译文/注释/题干） |
| P6 | 全量回归 + VLM 视觉验收 |
