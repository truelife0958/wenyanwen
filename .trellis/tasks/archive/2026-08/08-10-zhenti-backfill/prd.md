# 补录必考篇目真题

## Goal

为 29 个无真题的必考/核心篇目补录**真实中考真题**(网络搜索来源),格式对齐 `src/data/raw/zhenti_web.json`,重建 runtime 数据,使图谱/学习页真题覆盖完整。

## 缺口清单(29 篇)

论语十二章、十一月四日风雨大作（其二）、卖油翁、卜算子·咏梅、登幽州台歌、咏雪、夜雨寄北、天净沙·秋思、己亥杂诗(其五)、春望、望岳、望洞庭湖上张丞相、泊秦淮、渔家傲·秋思、渡荆门送别、游山西村、狼、登飞来峰、白雪歌送武判官归京、相见欢(无言独上西楼)、破阵子·为陈同甫赋壮词以寄之、茅屋为秋风所破歌、行路难（其一）、过零丁洋、送友人、送杜少府之任蜀州、酬乐天扬州初逢席上见赠、陈太丘与友期行、黄鹤楼

## Requirements

### R1 搜索与提取
- 用 exa 搜索每个篇目的中考真题(如"论语十二章 中考真题 阅读 题目"),每篇目标 2-4 道题。
- 优先取各省市中考试卷真题(带省份/年份标注)。
- 提取字段: title, province, year(如有), type, stem, answer, analysis(可选), material(可选,文言文阅读材料)。
- 格式完全对齐 zhenti_web.json(id 形如 `web-xxx-NNN` 增量,page: 0, source: "web")。

### R2 数据入库
- 追加写入 `src/data/raw/zhenti_web.json`(增量,保留已有 140 条)。
- 重新构建: `npm run data:build` → 校验: 29 篇全部有真题。

### R3 质量验证
- 每题: 题干完整、答案存在、归属篇目正确(文章 title 匹配)。
- 构建后图谱/学习页真题数正确。
- `npm run check` + `test:flow` 无回归。

## Acceptance Criteria

- [ ] 29 篇全部至少 1 道真题(理想 2-4 道)。
- [ ] 真题格式与 zhenti_web.json 一致,无重复 id。
- [ ] 入库后 `validate` 0 错误,图谱真题覆盖 45+29 篇。
- [ ] 全部真题可追溯(来自真实中考卷,记录来源卷名)。
