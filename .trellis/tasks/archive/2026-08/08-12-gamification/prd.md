# 游戏化改造: 闯关地图 + XP等级 + 连击爽感 + 成就徽章 (古风奇幻UI)

## Goal

把"文言文学习"从传统学习工具改造成让初三生愿意持续学习的**游戏化学习体验**：超酷的古风奇幻界面、闯关地图、XP 成长、连击得分爽感、成就收集——每一小步都有成就感，激发学习兴趣。

## 背景

- 应用现状：Vite+React+TS 单页应用，数据 126 篇课文 + 129 篇默写（4 题型：原文/理解/词义/译文）
- 用户反馈：孩子没有学习下去的兴趣，界面传统（进度环+篇目网格），缺游戏感/爽感/成就感
- 已确认决策：四大机制全上（闯关地图 + XP等级 + 连击爽感 + 成就徽章），古风奇幻风格，完整改造

## 需求

### R1. XP 经验值 + 等级系统
- **R1.1** 每次默写判分获得 XP：答对 +10，全对（该题所有空）额外 +5；答错 +2（参与奖）
- **R1.2** 连击加成：连击 ≥3 时 XP ×1.2，≥5 时 ×1.5（取整）
- **R1.3** 等级曲线：Lv1 需 0，每级递进（level n 需 80+40×(n-1) XP 累加）
- **R1.4** 等级称号（古风）：Lv1 学童 → Lv2 蒙童 → Lv3 秀才 → Lv4 举人 → Lv5 贡士 → Lv6 进士 → Lv7 探花 → Lv8 榜眼 → Lv9 状元 → Lv10+ 文曲星
- **R1.5** 经验条动画：升级时闪金光 + "晋升！" 横幅

### R2. 连击 + 得分爽感
- **R2.1** 连续答对：combo+1；答错归零
- **R2.2** 连击特效：combo ≥3 出现燃烧火焰/飘字 "连击×3"，≥5 金色大字，≥8 满屏星光
- **R2.3** 得分飘字：每次判分得分数字向上飘散消失（+12 金色）
- **R2.4** 判分瞬间：答对绿色闪光 + "✓"，答错红色抖动 + 显示正确答案
- **R2.5** 音效（可选，需用户开启）：答对/答错/升级/连击提示音（WebAudio 合成，不引外部资源）

### R3. 闯关地图模式
- **R3.1** 默写首页改造为**关卡地图**：按年级分"世界"（七年级→八年级→九年级），每个世界一条蜿蜒的关卡路径
- **R3.2** 每篇默写 = 一个关卡节点：圆形徽章显示关卡号，通关后点亮（金色），未解锁为灰色锁
- **R3.3** 解锁规则：本世界按顺序解锁（通关上一篇解锁下一篇）；跨世界需本世界全部通关
- **R3.4** 星级评定：一篇内全部题全对 = ★★★，≥80% 正确 = ★★，≥60% = ★
- **R3.5** 关卡节点样式：已通关金色发光 + 星标，当前可玩跳动光圈，未解锁暗色锁图标
- **R3.6** 地图背景：暗色星空 + 水墨山峦剪影 + 金色路径，古风奇幻氛围

### R4. 成就徽章系统
- **R4.1** 成就定义（≥10 个）：
  - 初出茅庐：完成第 1 篇默写
  - 十全十美：累计全对 10 题
  - 百炼成钢：累计作答 100 题
  - 连击小达人：单次连击达 5
  - 连击大师：单次连击达 10
  - 过关斩将：通关 5 篇
  - 半壁江山：通关 10 篇
  - 全胜将军：通关 20 篇
  - 进士及第：等级达 5
  - 状元及第：等级达 9
  - 锲而不舍：连续学习 3 天
  - 焚膏继晷：连续学习 7 天
  - 一词千金：单题获得 15 XP（含连击加成）
  - 满腹经纶：完成全部 129 篇（隐藏成就，达成前显示 ???）
- **R4.2** 成就墙页面：徽章网格（金色/青铜/灰色），达成动画，未达成显示解锁条件
- **R4.3** 达成瞬间：全屏横幅 + 徽章弹出动画

### R5. 首页英雄区（学习概览游戏化）
- **R5.1** 顶部：等级徽章 + 称号 + 经验条（动画填充）
- **R5.2** 数据行：连续学习天数 🔥 / 今日 XP / 总关卡 / 成就数
- **R5.3** "继续学习"横幅保持，强化为"继续闯关 →"
- **R5.4** 首页卡片融入关卡进度（如"已通关 X/Y 篇"）

### R6. 古风奇幻视觉
- **R6.1** 新增暗色奇幻主题令牌：星空背景（深蓝紫渐变）、金色主调、水墨山峦 SVG、发光效果
- **R6.2** 组件级游戏化样式独立文件（game.css），不破坏现有学习内容页可读性
- **R6.3** 动画：关卡点亮、XP 飘字、升级金光、连击火焰、成就弹出——全部 CSS keyframes + 轻量 JS
- **R6.4** 字体：标题可用更大字号 + 字距，保持楷体/衬线阅读质感

## 非目标
- 不重构数据层/管道
- 不改变默写判分算法本身（仅接入游戏化回调）
- 不做真实音效文件（WebAudio 合成，可选）
- 不引入游戏引擎/重型依赖

## 验收标准
1. XP/等级/连击/成就/关卡状态持久化（localStorage），刷新不丢失
2. 闯关地图正确显示 129 篇关卡、解锁链、星级
3. 判分后 XP 飘字 + 连击特效正确触发
4. 成就达成正确触发（含隐藏成就）
5. 首页英雄区显示等级/经验/数据
6. 三套回归测试（browser 67 / page-scan 85 / full-flow 44）通过或按需同步更新
7. validate + typecheck 全绿
8. 部署 Vercel 验证线上

## 已确认决策
1. 四大机制全上：闯关地图 + XP等级 + 连击爽感 + 成就徽章
2. 视觉：古风奇幻（暗色星空 + 水墨山峦 + 金色主调）
3. 完整改造（首页 + 默写 + 关卡地图 + 成就墙）
