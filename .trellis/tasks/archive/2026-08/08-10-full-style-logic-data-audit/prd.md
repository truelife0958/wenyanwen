# 全项目样式/逻辑/数据全面排查

## Goal

对整个项目(首页/学习/练习/字词卡/图谱/错题本/背诵/移动端)做一次全面排查:
1. **样式**: 所有页面美观度、一致性、间距、配色、响应式问题
2. **逻辑**: 前端交互逻辑错误、状态管理 bug、边界情况
3. **数据**: 遗漏(缺字段/缺内容)、重复(重复词条/题)、错误(错别字/错误答案/错误归属)

发现问题**当场修复**;无法立即修的记录到报告。

## 排查范围

| 模块 | 样式 | 逻辑 | 数据 |
|---|---|---|---|
| 首页(统计/搜索/年级tab/卡片/徽章) | ✓ | ✓ | ✓ |
| 学习页(原文/注释/译文/7 tab/朗读/进度) | ✓ | ✓ | ✓ |
| 练习页(答题流/判分/结果页/错题入本) | ✓ | ✓ | ✓ |

| 考点图谱(筛选/计数/真题覆盖) | ✓ | ✓ | ✓ |
| 错题本(分组/移除/清空/空态) | ✓ | ✓ | ✓ |
| 移动端 375px 全页面 | ✓ | — | — |

## 方法

### R1 样式
- 每个页面截图 → VLM 视觉审查(若可用)或 playwright computed style 抽查
- CSS 全局一致性: 色值令牌使用、间距体系、圆角/阴影/字体
- 响应式: 375px / 768px / 1440px 三档无溢出

### R2 逻辑
- 交互路径逐一实测(点击/输入/键盘/边界)
- 状态持久化(localStorage)读写一致性
- 深链/回退/无效参数兜底

### R3 数据
- 全库校验脚本: 重复 id/重复词条、空值、悬空引用、OCR 残留
- 数字对账: README/首页统计 vs runtime 实际
- 抽查内容质量(翻译/注释/答案正确性, 每模块 3-5 处)

## Acceptance Criteria

- [ ] 排查记录完整(样式/逻辑/数据各一份清单)
- [ ] 所有 P0/P1 问题修复完成
- [ ] P2 记录在报告(含修复建议)
- [ ] `npm run check` + `test:flow` + `page-scan` 无回归
